# เว็บบันทึกรายรับ-รายจ่าย

## วิธีเปิดใช้งาน

1. ติดตั้ง Python 3
2. เปิด Command Prompt / Terminal ในโฟลเดอร์นี้
3. ติดตั้ง Flask:
   pip install flask
4. รันเว็บ:
   python app.py
5. เปิดเบราว์เซอร์ไปที่:
   http://127.0.0.1:5000

ข้อมูลจะถูกเก็บในไฟล์ `finance.db` อัตโนมัติ

## ฟังก์ชัน
- เพิ่มรายรับ/รายจ่าย
- จำนวนเงิน วันที่ หมวดหมู่ และหมายเหตุ
- คำนวณรายรับ รายจ่าย และยอดคงเหลือ
- ดูประวัติรายการ
- ลบรายการ
- กราฟรายรับ/รายจ่าย
- กราฟสัดส่วนรายจ่ายตามหมวดหมู่
